# Kriegsmarine Enigma Machine
This Kriegsmarine Enigma Machine has a manual mode and a JSON file mode.  
This Enigma Machine has an additional 3 rotors to choose from, as well as a fourth rotor slot with a choice of two rotors.

## Manual Operation
For manual operation, the following features are active:
- Semi-automatic reflector plate generation
  - No symmetrical reflector plate must be calculated by the user, as the program will do this for you providing that exactly 13 different letters are input into the system
- Pre-set rotors
  - There are 8 pre-set rotors avaible to be chosen, allowing 672 different rotor combinations
- Rotor positioning
  - Any number from 0-25 can be used as the starting rotation of each rotor, providing 17,576 starting positions
- Plugboard setting
  - Up to 10 letters can be chosen for each half of the plugboard, resulting in 150,738,274,937,250 possible combinations
- Fourth static rotor
  - This machine has a fourth rotor, which can be set to one of 26 positions, similar to the dynamic rotors. However, there are only two options for this rotor, and it does not rotate during use.

All of these combinations combine to provide 46,289,896,079,431,036,032,000 possible settings  
This is 46 sextillion, 289 quintillion, 896 quadrillion, 79 trillion, 431 billion, 36 million, 32 thousand settings  
This is just over 291 times more than the [Wehrmacht Enigma Machine](WEHRMACHTENIGMA.md)
